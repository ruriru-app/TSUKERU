# TSUKERU

授業中に評価を記録するための、端末内保存型チェック表です。

- アプリ: https://ruriru-app.github.io/TSUKERU/
- リポジトリ: https://github.com/ruriru-app/TSUKERU

## はじめに

1. 最初は「架空名簿で試す」を選び、操作と保存を確認してください。
2. 設定の「クラス設定」で、表計算ソフトから `出席番号 / 氏名 / よみがな` を貼り付けられます。
3. 設定の「シート設定」でチェック表を作り、トップ画面で記録するクラスを選びます。

## 端末内保存と個人情報

- データは、使用中の1台の端末・同じブラウザプロファイル内だけに保存されます。
- ChromeのWeb版とインストールしたPWAは、同じ端末・同じChromeプロファイル・同じURLなら同じデータを使います。
- Chrome端末とiPadは別データです。端末間・利用者間の自動同期はありません。
- 通常モードでは再読み込み後も入力が残ります。ただし「保存準備中」「保存失敗」の表示中、プライベートブラウズ、ブラウザデータ消去時は入力が消える可能性があります。
- 学校の実名簿を入力する前に、必ず架空名簿で保存・再読み込み・バックアップ復元を確認してください。

## オフラインで使う

- 最初の1回はオンラインでアプリを開き、読み込み完了を待ってください。
- ChromeではインストールしたPWA、iPadではSafariの共有メニューから「ホーム画面に追加」した版を継続して利用できます。
- 初回読み込み後は、校内Wi-Fiが届かない運動場などでも記録できます。
- 更新が表示された場合は、オンライン環境で更新してからオフライン利用を再確認してください。

## 手動バックアップ

1. 設定 → クラス設定 →「バックアップを保存」を押します。
2. 保存された `TSUKERU-backup-*.json` を、学校指定のGoogleドライブなどへ手動でアップロードします。
3. 復元するときは、同じ画面の「バックアップから復元」でJSONファイルを選び、内容の確認後に復元します。

バックアップには名簿・評価などの個人情報が含まれます。個人用アカウントや許可されていない保存先には置かないでください。端末故障に備え、授業後や大きな設定変更前に定期的なバックアップを推奨します。
