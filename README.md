# TSUKERU

授業中に評価を記録するための、端末内保存の試用版チェック表です。

- アプリ: https://ruriru-app.github.io/TSUKERU/
- リポジトリ: https://github.com/ruriru-app/TSUKERU
- データは使用中の端末・ブラウザだけに保存され、別端末とは同期されません。
- 初回だけオンラインで開いた後は、PWAとしてオフラインでも利用できます。
- iPadでは「ホーム画面に追加」した版を継続して利用してください。
- 最初は架空名簿で操作を確認できます。
- 端末故障に備えて、設定から定期的に手動バックアップを保存してください。
- バックアップには名簿・評価などの個人情報が含まれます。学校が指定する保存先だけに保管してください。
