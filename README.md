# TSUKERU

授業中に評価を記録するための、端末内保存型チェック表です。

- アプリ: https://ruriru-app.github.io/TSUKERU/
- リポジトリ: https://github.com/ruriru-app/TSUKERU

## はじめに

1. 最初は「架空名簿で試す」を選び、操作と保存を確認してください。
2. 設定の「クラス設定」で、表計算ソフトから `出席番号 / 氏名 / よみがな` を貼り付けられます。
3. 設定の「シート設定」でチェック表を作り、トップ画面で記録するクラスを選びます。
4. 記録画面では列の見出しをダブルクリック（iPadでは素早く2回タップ）すると、入力ロックを解除できます。初回だけ入力方法とパレットを選びます。

## パレットと点数

- 設定の「パレット設定」で、パレットに名前を付けて複数保存できます。文字、色、順番、表示・非表示、ボタンサイズを変更でき、複製してから編集することもできます。
- 「点数と連動する」を有効にすると、各表示に点数を対応させられます。列へ適用すると、そのパレットの最大点が列の配点になります。
- 初期プリセットは、提出物が `○ / × / 欠 / 再 / 日付 / 再返`、活動評価が `A / B / C / 欠` です。
- 列へ適用したパレットは列ごとに保存されるため、元のパレットを後で編集しても、すでに記録中の列は勝手に変わりません。

## 合同グループ

- 設定の「合同グループ」で、グループ名と所属クラスを登録できます。共有するシートは後から決められます。
- 記録画面上部のクラス選択には「クラス」と「合同グループ」が分けて表示されます。共有シートがまだない合同グループを選ぶと、現在開いているシートをそのグループの共有シートとして登録します。
- 合同表示ではクラスごとに名簿を区切り、児童の記録はクラス別に保存します。列名、配点、パレット、列順、集計対象は共通ですが、締切日はクラスごとに設定できます。
- 個別クラスへ戻っても、同じ共有シートをそのクラスの名簿だけで表示できます。

## 端末内保存と個人情報

- データは、使用中の1台の端末・同じブラウザプロファイル内だけに保存されます。
- ChromeのWeb版とインストールしたPWAは、同じ端末・同じChromeプロファイル・同じURLなら同じデータを使います。
- Chrome端末とiPadは別データです。端末間・利用者間の自動同期はありません。
- 通常モードでは再読み込み後も入力が残ります。ただし「保存準備中」「保存失敗」の表示中、プライベートブラウズ、ブラウザデータ消去時は入力が消える可能性があります。
- 「保存済み」の下に、最後に端末へ保存できた日時を表示します。授業後は時刻が更新されていることを確認してください。
- 学校の実名簿を入力する前に、必ず架空名簿で保存・再読み込み・バックアップ復元を確認してください。

## オフラインで使う

- 最初の1回はオンラインでアプリを開き、読み込み完了を待ってください。
- ChromeではインストールしたPWA、iPadではSafariの共有メニューから「ホーム画面に追加」した版を継続して利用できます。
- 初回読み込み後は、校内Wi-Fiが届かない運動場などでも記録できます。
- 更新が表示された場合は、オンライン環境で更新してからオフライン利用を再確認してください。

## 集計結果とチェック表を出力する

- 記録画面上部の「出力」から、Excel（.xlsx）、CSV（UTF-8）、記録入りPDF・印刷、空欄ひな形PDF・印刷を選べます。
- 現在のクラスだけ、または同じシートを使う全クラスを選べます。Excelではクラスごとに別シート、CSVでは全クラスを1つの表にまとめます。
- 表の右端にある「コピー」を押すと、画面に並ぶ児童の集計点だけを名簿順の縦一列でコピーできます。Excelの先頭セルを選んで貼り付けてください。「－」は空欄、0点は「0」のまま貼り付けられます。
- 印刷はA4縦向けの専用画面を開き、ブラウザの標準印刷画面で「PDFに保存」またはプリンターを選びます。列が10列以上ある場合は9列ごとに分け、番号・氏名欄を各ページに繰り返します。
- ファイルと印刷画面は端末内で生成され、TSUKERUから外部サービスへ送信しません。
- 出力には名簿・評価などの個人情報が含まれます。保存後は、学校が指定するGoogleドライブ等の保存先だけで管理してください。

## 手動バックアップ

1. 設定 → クラス設定 →「バックアップを保存」を押します。
2. 保存された `TSUKERU-backup-*.json` を、学校指定のGoogleドライブなどへ手動でアップロードします。
3. 復元するときは、同じ画面の「バックアップから復元」でJSONファイルを選び、内容の確認後に復元します。

バックアップには名簿・評価などの個人情報が含まれます。個人用アカウントや許可されていない保存先には置かないでください。端末故障に備え、授業後や大きな設定変更前に定期的なバックアップを推奨します。

## 現在の注意

- 試用版です。授業で使う前に、架空名簿で一連の操作を確認してください。
- 永続保存はこの端末のブラウザ内だけです。別端末との同期やクラウドへの自動保存はありません。
- Excel・CSV・印刷用PDFは記録の閲覧・集計用です。端末故障からの復元にはJSONバックアップを使用してください。
- 年度データ削除は端末内の名簿・評価・シートを消しますが、すでに書き出したバックアップやGoogleドライブ上のファイルは削除しません。
